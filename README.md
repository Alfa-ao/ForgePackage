# ForgePackage

**ForgePackage** - консольный менеджер зависимостей для аддонов Allods Online. 
Инструмент автоматизирует загрузку, обновление и удаление сторонних библиотек с GitHub, а также управляет файлом `AddonDesc.(UIAddon).xdb`, корректно расставляя приоритеты загрузки Lua-скриптов.

## Возможности

- Автоматическая загрузка библиотек и их вложенных зависимостей с GitHub.
- Генерация и обновление `AddonDesc.(UIAddon).xdb` с учетом приоритетов скриптов.
- Управление файлом `forge.json` для аддонов и библиотек.
- Создание резервных копий папки `Packages` и файла `xdb` перед внесением изменений.
- Автоматическая проверка обновлений самого скрипта.

## Требования

- Операционная система Windows.
- PowerShell 5.1 или выше.

## Запуск

Для запуска приложения требуется выполнить файл `run.bat`.
Скрипт автоматически настроит кодировку консоли и запустит `ForgePackage.ps1`.

## Режимы работы

При запуске предлагается выбрать один из двух режимов:

- **Addon** - сканирование папки с аддонами. Предназначен для разработчиков аддонов, использующих сторонние библиотеки.
- **Library** - создание `forge.json` для библиотеки. Предназначен для авторов библиотек, готовящих свой код к публикации.

## Команды управления - Addon

В режиме работы с аддоном доступны следующие команды:

- `install` - установить все зависимости, указанные в `forge.json`.
- `require <Владелец/Репозиторий>` - подключить новую библиотеку.
- `remove <Владелец/Репозиторий>` - удалить библиотеку и очистить файлы.
- `update all` - обновить все установленные библиотеки до последних версий.
- `update <Владелец/Репозиторий>` - обновить конкретную библиотеку.
- `exit` - завершить работу скрипта.

## Структура конфигурационных файлов

### forge.json

Файл описывает метаданные текущего проекта (аддона или библиотеки) и его зависимости.

**Пример для аддона:**
```json
{
    "name": "LibreAlchemyV2",
    "description": "",
    "type": "Addon",
    "version": "2.4.0",
    "license": "MIT",
    "authors": [
        {
            "name": "Alfa-ao"
        }
    ],
    "require": {
        "api": "17.0.01.67",
        "useCommonScripts": true,
        "Alfa-ao/DnDManager": "v1.2.1",
        "Alfa-ao/Enum": "v1.1.0"
    },
    "files": {
        "Scripts/Config.lua": 50,
        "Scripts/Main.lua": 0
    }
}
```

**Пример для библиотеки:**
```json
{
    "name": "Debug",
    "type": "Library",
    "execute": {
        "unpack": [
            "var_dump.lua"
        ]
    },
    "files": {
        "var_dump.lua": 21
    }
}
```

**Описание полей:**
- `name` - имя проекта.
- `type` - тип проекта `Addon` или `Library`.
- `require` - список зависимостей. Для аддонов включает `api` и `useCommonScripts`. Для библиотек может содержать другие библиотеки.
- `files` - список файлов и их приоритетов загрузки.
- `execute.unpack` - "только для библиотек `Library`" список файлов, которые необходимо извлечь при установке.

### packages.json

Файл формируется автоматически в папке `Packages`. Хранит информацию об установленных зависимостях, их версиях и списках файлов. Изменение файла вручную **не рекомендуется**.

## Для авторов библиотек

Чтобы библиотека поддерживалась ForgePackage, в корне репозитория должен находиться файл `forge.json`. 
Релизы на GitHub должны быть оформлены через механизм Tags (теги). Скрипт скачивает файлы, указанные в `execute.unpack`, напрямую из raw-контента репозитория по указанному тегу.
